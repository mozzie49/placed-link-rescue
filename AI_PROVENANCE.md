# Authorship and provenance

This experimental v0 was designed and implemented with an OpenAI coding assistant on 2026-10-01, including the skill, helper, tests, documentation and original synthetic publication artwork. It has had automated tests and separate agent code reviews; it has not had an independent human security audit or real InDesign production validation.

No user-private PDF, source publication, stock art, company logo or paid template was used. The fictional FIELDNOTES magazine, STILL STUDIO and NORTH SIGNAL ads use original shapes/writing and reserved example.org destinations. They are test illustrations, not real businesses or endorsements. The fixtures embed Bitstream Vera fonts supplied by ReportLab; those fonts retain their own license, reproduced in FONT_LICENSE.txt. No third-party project source code was copied or vendored.

PDF link copying is established functionality. The project contribution is the scoped recovery workflow: reviewed input-hash-bound placements, hotspot proof, preservation checks, refusal behavior and a self-contained assistant skill. It does not claim invention of annotation copying or uniqueness against every existing tool.

Dependencies are separately licensed: pypdf (BSD-3-Clause), Pillow (HPND), ReportLab (BSD-style), Poppler (GPL family). The optional independent-test PyMuPDF dependency is AGPL/commercial. This repository's original code/artwork is MIT; that does not relicense dependencies. The tools are installed independently from their official distributions and are not bundled here.
